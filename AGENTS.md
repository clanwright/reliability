Do not add project-owned Python runtime, tests or generators. Use upstream tools regardless of their implementation language.

The lead owns architecture, integration and delivery; workers edit only assigned files. Provider, secret, deployment, real backup, restore and prune operations require explicit owner authorization. External Apps and Primitives implementations must not be inspected or changed.

No secret values, provider account names, real machine topology or credentials in code/docs/test output. Use fake data for tests. No remote/provider operations from workers. Never delete real backup data. Preserve test evidence under ignored .work. Test the canonical NixOS example and real Restic on temporary local repositories. File backup and repository checks do not establish database consistency or semantic application recovery. Target Linux services and macOS local tooling. No hosted CI or virtual-machine/QEMU tests; use local checks and documented Linux builder when needed. Actual manager/same-host runtime proof is required at PREDEPLOY, not a blocker for local source refactor. Do not create a privileged runner/test host or introduce credential, privilege or isolation workarounds. Record unobserved cases in the canonical predeployment matrix and never claim them PASS from static/process checks. Documentation index is README.md; commands belong in docs/operations.md.
